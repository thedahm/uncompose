# Spike: cross-engine sync-test harness (issue #73)

Throwaway proof that the tested sync contract from #66 runs green on
Chromium, Firefox, and WebKit before it anchors Compare's v0.1 definition
of done. Not production code; the real harness lives in
`thedahm/uncompose-compare` when that repo exists.

## What it proves

The real playback-graph shape (three sample-locked buffer sources into
per-lane gains, SRC muted, mid-render 10 ms linear crossfade A→B) rendered
in `OfflineAudioContext(2ch, 66150 frames, 44.1 kHz)` satisfies, on all
three Playwright engines:

1. **Zero-offset render** — cross-correlation of the post-switch output
   against the expected candidate peaks at exactly lag 0 (±256 lags
   searched, peak ≈68× the runner-up).
2. **Decode-count canary** — WAV and FLAC fixtures decode to exactly
   66150 frames, 44100 Hz, 2 channels on every engine.
3. **Crossfade bound** — output is float-bit-identical to the live
   candidate outside the fade window. Zero mismatched samples, both
   channels, all engines; no guard band needed.

## Findings beyond "it passes"

- **Fixture licensing is a non-issue**: fixtures are deterministic seeded
  noise generated by `gen-fixtures.mjs` (WAV written directly, FLAC via
  ffmpeg). Noise, not sine, so the correlation peak is unambiguous.
- **Runtime is trivial**: ~2 s wall for all 9 tests across 3 engines with
  browsers cached; render itself is 84–176 ms in-page. CI cost is browser
  install, not the tests.
- **Bit-identity holds strictly**: gain 1.0 is exact pass-through and
  `linearRampToValueAtTime` lands exactly on target at ramp end in all
  three engines, so the contract can demand `===` equality with no
  epsilon and no guard samples around the window.
- **decodeAudioData resamples to the context rate**, so the offline
  context must be constructed at the fixture rate (44100) or the
  decode-count canary is meaningless.
- **WebKit on non-Ubuntu hosts is the only friction**: Playwright's WPE
  build needs libicu74/libxml2.so.2/libmanette. On GitHub-hosted
  `ubuntu-latest` runners `npx playwright install --with-deps` covers it;
  this spike ran on a non-Ubuntu box by extracting the Ubuntu debs into
  the bundle's `sys/lib`. No Web Audio quirks in WebKit itself.

## Run it

```sh
npm install
npx playwright install chromium firefox webkit
node gen-fixtures.mjs   # needs ffmpeg for the FLAC pair
npx playwright test
```
